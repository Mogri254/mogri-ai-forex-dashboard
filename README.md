# MOGRI AI Forex Signal Dashboard

Vercel-ready static dashboard for the first demo version.

## Deploy
1. Upload these files to a GitHub repository.
2. In Vercel choose **Add New Project** and import the repository.
3. Framework preset: **Other**.
4. Build command: leave empty.
5. Output directory: leave empty.
6. Deploy.

## Important
The current `app.js` contains a DEMO signal engine with simulated market conditions. It does NOT use live prices and must not be used as a real-money signal service.

Next development step: replace the demo engine with a real market-data feed and add historical backtesting before enabling live alerts.
